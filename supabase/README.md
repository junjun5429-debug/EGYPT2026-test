# 思い出フォト Supabase セットアップ

1. Supabase Dashboardで対象プロジェクトを開きます。
2. SQL Editorで `memories-setup.sql` の全内容を実行します。
3. Authentication > Providersを開きます。
4. Email providerを有効にします。
5. Authentication > URL ConfigurationのRedirect URLsへ次を追加します。
	- `http://127.0.0.1:8000/memories.html`
	- `https://junjun5429-debug.github.io/EGYPT2026-test/memories.html`

## ニックネームとパスワード認証

ログイン画面では `JUNPEI`、`KAZUKI`、`TAKUYA` のいずれかを選択します。初回はメールアドレスと8文字以上のパスワードでSupabase Authへ登録します。同じブラウザーではメールアドレスをローカルストレージへ記憶し、2回目以降はパスワードのみで認証します。パスワードは保存しません。

メール確認が有効なため、初回登録後は確認メール内のリンクを開いて登録を完了します。

別の端末やブラウザーでは「すでに登録済みの方」を選び、最初の1回だけメールアドレスとパスワードを入力します。認証後は同じニックネームで保存された写真を共通の「自分の写真」として扱います。

各ニックネームは最初にメール確認を完了した1つの認証アカウントへ割り当てられます。別の認証アカウントから同じニックネームを取得することはできません。

`memories` バケットは非公開です。SQLのRLSポリシーにより、ニックネームを取得した3人だけが全員の写真を閲覧できます。写真の追加は認証ユーザーIDごとの保存先に制限され、編集・削除は割り当てられたニックネームが一致する利用者に許可されます。それ以外のユーザーは閲覧できません。
